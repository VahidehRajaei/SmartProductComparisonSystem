# Smart Product Comparison System

AI-powered product comparison system that searches products from Trendyol and Hepsiburada and shows similar products using Machine Learning / Deep Learning techniques.

---

## Features

- Search products
- Compare prices from Trendyol and Hepsiburada
- Show similar products
- Product recommendation system
- Web scraping integration
- User-friendly interface

---

## Technologies Used

- Python
- Selenium
- BeautifulSoup
- Machine Learning 
- Tkinter 
- Pandas
- Scikit-learn

---

## Project Structure

```text
Data_Access_Layer/
Presentation_Layer/
Utilities_Layer/
main.py
requirements.txt
```

---

## Installation

Clone repository:

```bash
git clone https://github.com/VahidehRajaei/SmartProductComparisonSystem.git
```

Install requirements:

```bash
pip install -r requirements.txt
```

Run project:

```bash
python main.py
```
